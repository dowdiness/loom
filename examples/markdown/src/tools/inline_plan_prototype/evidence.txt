Interpretation
--------------
- No added combined-consumer cost was observed outside the measured paired
  control envelope on either target. This is a feasibility result, not a
  general production-performance certification.
- Angle-free input does not enter the angle path or build its index/fact array.
- Shared-closer index assertions rule out repeated nearest-closer discovery.
  Timing growth is reported as an adversarial control; it is not claimed as a
  formal wall-time complexity proof.
- Classification timing is existing lexer-shell work, not added plan-consumer
  overhead. Production integration must reuse those facts rather than rerun
  classification.
